📶 Network Setup

Connect the analyzer to your local WiFi network

📡 Network Mode

Normally the analyzer joins one of your saved networks. In access-point mode it becomes its own Wi-Fi network instead, so it can be used where there is none — the whole web interface still works.

🔧 IP Configuration

Addressing is stored per network, so the analyzer can hold a fixed address at one site and use DHCP everywhere else.

A static address is checked with an ARP probe before saving. A device that is powered off still owns its address but will not answer, so a successful check is not proof the address is free.
